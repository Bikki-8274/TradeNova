# TradeNova

TradeNova is a Full Stack Stock Trading & Portfolio Management Platform that enables users to manage investments through a clean and responsive interface.

## 🚀 Features

- User Authentication
- Dashboard
- Stock Holdings Management
- Orders Management
- Portfolio Tracking
- Responsive UI
- REST API Integration
- MongoDB Database

## 🛠️ Tech Stack

### Frontend
- React.js
- Bootstrap
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## 📂 Project Structure

```
TradeNova/
│── frontend/
│── backend/
│── README.md
```

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Bikki-8274/TradeNova.git
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
npm install
npm start
```
